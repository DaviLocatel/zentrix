# Zentrix - Agência Web

Plataforma institucional e portfólio da Zentrix, especializada em criar sites profissionais e otimizados para pequenas empresas.

## O problema
Pequenas empresas precisam de presença digital rápida, bonita e que gere contatos via WhatsApp, mas orçamentos de agências grandes são inviáveis. A Zentrix resolve isso entregando sites completos e responsivos de forma direta.

## Telas (Single-Page Application)
| Seção | O que faz |
|---|---|
| Início (Hero) | Apresentação de impacto com Call-to-Action (CTA). |
| Serviços | Mostra as soluções (Landing page, Site Profissional, Cardápio). |
| Como Funciona | Passo a passo transparente (Conversa, Criação, No Ar). |
| Pacotes | Transparência de preços (Site Completo e Manutenção). |

## Tecnologias
- **HTML5 Semântico:** Uso de `<header>`, `<nav>`, `<main>`, `<section>`.
- **CSS3:** Variáveis (`:root`), Grid, Flexbox, Animações (`@keyframes`), Transições e Mobile First.
- **JavaScript:** Manipulação de DOM e injeção dinâmica de links de WhatsApp.
- **SQL:** Estrutura de banco de dados para gestão de clientes e pacotes (Projeto Integrador).

## Como rodar
1. Extraia os arquivos.
2. Abra o `index.html` no navegador ou use o Live Server no VS Code.
3. Para ativar o WhatsApp, edite a variável `WHATS` dentro de `script.js` com o seu número.
